# SkillSphere development roadmap

- [ ] Phase 1 — Landing page, Cloud foundation, registration, sign-in, password recovery, private profiles and secure account roles; verify flows.
- [ ] Phase 2 — Five role-specific dashboards, account verification and management.
- [ ] Phase 3 — Profiles and uploads, opportunities, applications, mentorship, fellowships, returnships and transparent matching.
- [ ] Phase 4 — Analytics, reports, notifications, validation and security testing.
- [ ] Phase 5 — Production configuration, deployment documentation and publishing.

Later phases are held until the preceding phase is functional, as requested.
